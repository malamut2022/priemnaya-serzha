# Приёмная Сержа

Сайт с виртуальным секретарём Полиной. Посетитель пишет или говорит, Полина пишет в блокноте,
отвечает своим голосом готовыми фразами, а поручение сразу приходит Сержу в Telegram.

**Два режима:**
- **Бесплатный (по умолчанию).** Ключ ИИ не нужен. Полина ведёт разговор по сценарию:
  имя → что передать → контакт → срочно ли → «что-нибудь ещё?» → прощание.
- **С ИИ (по желанию).** Если добавить ключ OpenAI или Claude, Полина понимает свободную речь и
  отвечает гибко. Платно, по факту использования (доли цента за ответ).

## Что где лежит

| Файл / папка | Что это | Можно править? |
|---|---|---|
| `api/_polina-config.js` | **Характер и правила Полины**, её фразы, ограничения | Да, в первую очередь здесь |
| `index.html` | Сама страница: видео, окно разговора, микрофон, **сценарий бесплатного режима** (функция `scriptReply`) | Да, внешний вид и тексты |
| `api/polina.js` | Связь с ИИ (OpenAI или Claude) | Обычно не нужно |
| `api/task.js` | Отправка поручений в Telegram | Обычно не нужно |
| `say/*.mp4` | Фразы Полины её голосом (из HeyGen) | Можно заменить или добавить |
| `writing.mp4` | Полина пишет в блокноте | Можно заменить |

## Запуск (один раз, около 15 минут)

### 1. Telegram-бот (куда будут приходить поручения)
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя (например «Приёмная Сержа») и адрес бота.
2. BotFather пришлёт **токен** вида `123456:ABC-...` — сохраните его.
3. Откройте своего нового бота и нажмите **Start**. Без этого бот не знает, куда писать.

### 2. Ключ ИИ — только если нужен режим с ИИ (можно пропустить)
- **OpenAI:** platform.openai.com → API keys → Create new secret key. Пополните баланс на $5–10
  и в Limits поставьте месячный лимит расходов, например $5.
- **или Claude:** console.anthropic.com → API Keys.

### 3. Выложить на GitHub
1. github.com → **New repository** → имя `priemnaya-serzha` → Create.
2. **Add file → Upload files** → перетащите всё содержимое этой папки (вместе с папками `api` и `say`) → **Commit changes**.

### 4. Опубликовать на Vercel (бесплатно)
1. vercel.com → войдите через GitHub → **Add New → Project** → выберите `priemnaya-serzha` → **Import**.
2. Раскройте **Environment Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` = токен от BotFather
   - *(необязательно)* `OPENAI_API_KEY` = ключ OpenAI или `ANTHROPIC_API_KEY` = ключ Claude — включает режим с ИИ
3. **Deploy**. Через минуту появится адрес вида `priemnaya-serzha.vercel.app` — это ваша приёмная.
4. Зайдите на сайт, поговорите с Полиной — поручение должно прийти в Telegram.

Необязательные настройки (там же, Environment Variables):
- `OPENAI_MODEL` — модель OpenAI (по умолчанию `gpt-5.4-mini`)
- `ANTHROPIC_MODEL` — модель Claude (по умолчанию `claude-haiku-5-5`)
- `TELEGRAM_CHAT_ID` — номер чата, если поручения должны идти не вам, а, например, в группу

После любого изменения переменных: Vercel → Deployments → ⋯ → **Redeploy**.

## Как править через ChatGPT
Подключите GitHub к ChatGPT (Настройки → Приложения / Connectors → GitHub) и дайте доступ к репозиторию
`priemnaya-serzha`. Дальше можно писать, например:
- «В репозитории priemnaya-serzha в файле api/_polina-config.js сделай Полину строже и пусть всегда уточняет телефон»
- «Поменяй в index.html заголовок на "Приёмная Сергея"»

Каждое изменение в GitHub Vercel публикует сам примерно за минуту.

## Как добавить новую фразу голосом
1. Сделайте в HeyGen ролик с фразой (тот же аватар Polina, голос «Полина 25.06», формат 16:9).
2. Обрежьте тишину по краям и положите в `say/` с коротким латинским именем, например `say/thanks.mp4`.
3. Допишите её в `PHRASES` в `api/_polina-config.js` и в `CLIPS` в `index.html`.

## Что важно знать
- Разговор посетителя хранится только в его браузере, на сервере ничего не сохраняется. Копия каждого
  поручения приходит вам в Telegram.
- Микрофон работает в Chrome, Edge и Safari. Где не работает, можно надиктовать с клавиатуры телефона.
- Сайт открыт всем, у кого есть ссылка. Ограничения от злоупотреблений — в `LIMITS` в `api/_polina-config.js`.
